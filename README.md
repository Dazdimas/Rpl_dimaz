# Rpl_dimaz


Nama Use Case: Pencatatan Pengeluaran Harian

Aktor: Pengguna (Kamu)

Pre-condition: Pengguna sudah login dan memiliki saldo awal.

Alur Utama (Main Flow):

Pengguna membuka halaman Dashboard.

Pengguna memasukkan data pengeluaran (nama transaksi & nominal).

Sistem memvalidasi data input.

Sistem menyimpan transaksi ke database.

Sistem menghitung ulang total pengeluaran dan sisa saldo.

Sistem menampilkan saldo terbaru di layar secara real-time


Web pencatat keuangan harian dengan kalkulasi saldo otomatis (running balance). Pengguna cukup memasukkan saldo awal dan input pengeluaran harian, lalu sistem akan menghitung total pengeluaran serta membawa sisa saldo ke hari berikutnya secara real-time. Sederhana, akurat, dan sangat ideal untuk dokumentasi proyek RPL.
