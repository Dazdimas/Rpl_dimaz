# 💰 Pencatat Keuangan Harian (RPL)

Aplikasi web sederhana untuk mencatat dan memantau arus kas harian (pemasukan & pengeluaran) berbasis Python Flask.

## 🚀 Fitur Utama
- Menentukan saldo awal
- Mencatat transaksi pemasukan dan pengeluaran
- Menampilkan ringkasan sisa saldo secara otomatis
- Riwayat transaksi yang terstruktur

## 🛠️ Teknologi yang Digunakan
- **Backend:** Python (Flask Framework)
- **Frontend:** HTML5, CSS3
